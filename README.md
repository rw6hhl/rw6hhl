RSSI Controller V.2.3
Программа для управления выходным сигналом на основе уровня RSSI с OLED дисплеем, сохранением настроек в EEPROM и расширенными функциями управления.

Программы полностью сгенерирована ИИ на платформе https://chat.deepseek.com
Задание параметров Владимир RW6HHL
В задании использована информация размещенная Adrian YO3HJV 
https://github.com/yo3hjv/HAM-Repeater-Controlle_-HArSeR-Controller-/releases/tag/R.2.0.5


📋 Основные функции
Мониторинг RSSI в реальном времени (0-5000 единиц)

Настраиваемые пороги срабатывания:

Высокий порог (0-5000)
Низкий порог (0-5000)
Управление таймерами:
Защита от керчакинга (50-500 мс)
Время удержания (50-500 мс)
Время фрагментации (50-500 мс)
Настройка количества измерений (1-10)
Выбор уровня активации выхода (HIGH/LOW)
Сохранение всех параметров в EEPROM
Автоматическое закрытие меню через 30 секунд бездействия
Быстрая регулировка параметров при длительном нажатии кнопок

🎛 Управление
Кнопки:
MODE (D2) - переключение между режимами
PLUS (D3) - увеличение значения
MINUS (D4) - уменьшение значения

Режимы работы:
MODE_DISPLAY - режим мониторинга
MODE_HIGH - установка высокого порога
MODE_LOW - установка низкого порога
MODE_COUNT - количество измерений
MODE_KERCHUNK - защита от керчакинга
MODE_HOLD - время удержания
MODE_FRAG - время фрагментации
MODE_OUTPUT_LEVEL - уровень активации выхода

🚀 Быстрая регулировка
Короткое нажатие
Долгое нажатие (>500 мс) - быстрая регулировка на 10 единиц каждые 100 мс

📊 Дисплей
В режиме мониторинга:
Текущее значение RSSI (0-5000)
Состояние выхода (ON/OFF)
График RSSI с маркерами порогов L и H
Подписи порогов под маркерами

В режиме настройки:
Название параметра
Текущее значение
Единицы измерения
Обратный отсчет до закрытия меню
Инструкция по управлению

💾 Сохранение настроек
Все параметры автоматически сохраняются в EEPROM:
При выходе из меню настроек
После 30 секунд бездействия в меню
При первом запуске загружаются значения по умолчанию

🔧 Технические характеристики
Входные сигналы:
RSSI вход (A0): 0-5В через делитель 100 кОм → 0-5000 единиц

Выходные сигналы:
Выход управления (D12): конфигурируемый уровень (HIGH/LOW активный)

Питание:
Напряжение: 5V

Потребление: < 100 мА

OLED Display (128x64, I2C)
    VCC ─── 5V
    GND ─── GND
    SCL ─── A5
    SDA ─── A4

    OUTPUT ── D12 ────┐

⚙️ Настройка по умолчанию
cpp
highThreshold = 4000     // Высокий порог
lowThreshold = 3000      // Низкий порог  
readingsCount = 3        // Количество измерений
kerchunkTimer = 15       // 150 мс защита
holdTime = 10            // 100 мс удержание
fragmentationTime = 20   // 200 мс фрагментация
outputLevel = 1          // HIGH активный

🔄 Алгоритм работы
STATE_IDLE - ожидание сигнала
STATE_CHECK - проверка стабильности сигнала
STATE_ACTIVE - активная передача
STATE_FRAG - фрагментация при потере сигнала
STATE_HOLD - удержание после фрагментации
